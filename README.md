# traverse-framework/website

Public site and docs for [Traverse Framework](https://traverse-framework.com)
(Astro → static HTML on GitHub Pages).

```bash
npm ci
npm run build    # astro build + sitemap
npm test         # node --test
npm run test:e2e # Playwright (after npx playwright install)
npm run dev
```

Contribute: see [How do I contribute to Traverse?](https://traverse-framework.com/questions/how-do-i-contribute-to-traverse.html)
and open `help wanted` issues across the org. Site-specific starter: [#83](https://github.com/traverse-framework/website/issues/83).

Governance pin: `.governance-version`.
